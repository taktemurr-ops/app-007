# Tarif 360 privacy notes

Recipe content, favorites, meal plans and shopping lists are saved locally with platform-backed secure storage. No cloud login, analytics or tracking SDK is included. JSON copy/export is unencrypted once placed on the system clipboard and should be handled as potentially private. A user-initiated restore replaces all current recipe data after input validation.

This source is a development snapshot, not a store-ready release. Signing, Android/iOS device tests, localization review, app store metadata and any production premium/ad integrations remain subject to release acceptance.
